# 为什么又开了一个博客

已经有一组学习站了，为什么还要单独开博客？

因为学习站和目标博客不是一回事。学习站是课程，讲究结构、顺序和可复制；博客更像工作台，允许记录半成品、失败尝试和当时还没想明白的问题。两者混在一起，最后往往会为了“课程完整性”把很多真实过程删掉。

## 这个博客写什么

目前定下来四类内容：

1. **建站与工具链**：VitePress、Vercel、DNS、Git、SSH。
2. **学习复盘**：把踩过的坑压缩成下次能直接照做的步骤。
3. **安全与 Linux**：命令、排查思路、CTF 题解和靶场笔记。
4. **数据与代码**：Python、数据清洗、可视化，以及一些项目记录。

## 为什么还是 VitePress

本站继续用 VitePress，原因很实际：

- 学习站已经用同一套技术栈，维护成本低；
- Markdown 写作足够快，代码块、目录、搜索都是现成的；
- 构建结果就是静态文件，丢到 Vercel 就行；
- 想改 UI 时可以直接写 Vue 组件，不用被主题绑死。

这次没有直接套现成主题，而是自己写了一个很轻的博客层：首页、文章归档、标签筛选和文章元信息，其余继续复用 VitePress 默认主题。这样既能保持阅读体验，也不会让依赖变重。

## 接下来

先把站点跑起来，再慢慢把以前散落在各处的笔记搬过来。不会为了更新而更新，但每一篇都尽量做到：

- 有明确结论；
- 有可复制的命令或代码；
- 明确写出适用范围和翻车点。

如果这些内容对你有用，欢迎从 [文章列表](/posts/) 开始逛。
